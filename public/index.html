Claude Galaxy へようこそ

      
複数の Claude Code を並べて動かし、承認・ジョブ・記録を 1 か所で扱うアプリです。まずは次の 3 つを試してください。

      
    
        
  1. プロジェクトのフォルダを登録するホームの 3D グラフと、窓口の振り分け先の候補になります。
    2. 
        
  2. 最初のセッションを起動する作業ディレクトリを選んで Claude Code を起動します。
    3. 
        
  3. 診断で前提を確かめるclaude・hook・共有バスが動くかを確かめます。権限確認は左上の「承認待ち」に出ます。
    4. 
      

      
どこからでも Ctrl K で、やりたいことを書いたり、画面やセッションに移動したりできます。
